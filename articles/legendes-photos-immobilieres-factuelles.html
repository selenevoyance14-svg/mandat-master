Photos immobilières : écrire des légendes factuelles

Préparez des légendes courtes qui identifient les pièces et les vues, sans inventer une surface, un usage autorisé ou une caractéristique non vérifiée.

Nommer ce qui est visible

Une légende peut préciser la pièce ou le point de vue sans multiplier les adjectifs. Évitez de déduire une orientation, une surface ou un statut particulier à partir de la photographie. Si l’information vient d’un document, conservez sa référence dans le dossier et vérifiez sa pertinence avant publication.

Expliquer une vue qui pourrait être ambiguë

Distinguez une pièce principale d’une annexe ou une vue sur l’environnement d’un espace inclus. Le texte doit aider à comprendre l’image, pas corriger une photographie trompeuse. Si une image nécessite trop d’explications pour être comprise correctement, envisagez un autre cadrage ou une vérification sur place.

Relire les légendes avec le texte de l’annonce

Vérifiez que les noms des pièces restent cohérents sur tous les supports. Une légende ancienne ne doit pas être réutilisée après un changement de sélection sans contrôle. Gardez les descriptions factuelles et laissez les mentions réglementaires être examinées selon les règles applicables au dossier.

Photo : [nom de fichier]. Pièce ou vue : [désignation]. Légende proposée : [phrase factuelle]. Information à confirmer : [point]. Source de la précision : [document / interlocuteur].
